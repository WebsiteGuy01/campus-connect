# CampusConnect

A modern, scalable University Clubs Portal built with Next.js, TypeScript, Tailwind CSS, and modern web technologies.

## Vision

CampusConnect serves as the official hub for all university student organizations.

The platform will support:

- Microsoft Student Ambassador Club
- AWS Club
- Robotics Club
- Programming Club
- Debate Club
- Media Club
- Entrepreneurship Club
- Sports Clubs
- Future student organizations

## Planned Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- Framer Motion
- Supabase
- Vercel
