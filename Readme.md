## 📖 Overview

CampusConnect is a modern web platform designed to become the central hub for all student organizations at a university.

Instead of every club maintaining separate websites and social media pages, CampusConnect provides a single, unified platform where students can:

- Discover clubs
- Join communities
- Register for events
- Read announcements
- Explore galleries
- Access club resources
- Connect with student leaders

The architecture is designed to scale from a few clubs to an entire university ecosystem.
